|------------|---------------------|----------------------------------------------------------------------------|

| 36-45      | Above 75 lakhs      | Full medical + stress test + 2D Echo + chest X-ray                         |
| 46-55      | Up to 10 lakhs      | Basic medical                                                              |
| 46-55      | 10 lakhs - 50 lakhs | Full medical + stress test + 2D Echo + chest X-ray                         |
| 46-55      | Above 50 lakhs      | Full medical + stress test + 2D Echo + specialist opinion                  |
| 56-65      | All amounts         | Full medical + stress test + 2D Echo + chest X-ray + renal function        |
